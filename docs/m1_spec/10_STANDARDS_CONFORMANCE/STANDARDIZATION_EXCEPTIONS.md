# Standardization Exceptions

- **PH-EX-001 / KEEP** — Peer/Stream/Record/Offset remain the only Core concepts through all required and optional roadmap work.
- **PH-EX-002 / ADAPT** — M1 first-party modules are not dynamically installable extensions; the generic Extension Host starts at M2.0.
- **PH-EX-003 / PASS** — Do not force Engram-style lifecycle verb hierarchy onto communication resources; it would reduce clarity.
