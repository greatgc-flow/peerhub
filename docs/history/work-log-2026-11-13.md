## 5. Lessons recorded

- Pass `--timeout-seconds` on implementer and review asks (default 60 s; lesson `ask-timeouts`, #350).
- Cross-family review catches what one family misses (0.24.10: the compact small-height priority inversion).
- Measured numbers must be checked in before they appear in a CHANGELOG (0.24.8 benchmark figures).
- POSIX-only tests are skipped on Windows; run the full OS matrix before merging layout changes (0.24.10).
- Implementers must not leave repo-local temp folders or permission shims; cleaned twice in Engram.

## 5b. Other findings

- Reset coupons: the Claude app shows Fable and weekly reset coupons; the CLI exposes only a cached boolean `unusedLimitResetStatusCache.holdsUnusedReset` (no count, type or redeem command).
- Sub-agents: every peer can fan out through `peerhub ask` (cc `Agent`, cx `spawn_agent` when named explicitly, ag `invoke_subagent`); `/loop`-style persistence does not exist inside an ask (#361).
- Engram v3.11.12 hidden launch was verified on Windows 11 with a stub `engram.cmd` (conhost and Windows Terminal; first run visible; no leftovers); the hosted sandbox gate needed one whole rerun for the known rate-limited hold.
