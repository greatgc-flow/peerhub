## Prevention adopted

- Record durable requirements in the [registry](../requirements.md) or on a tracked issue. The [registry test](../../tests/communication/package/test_requirements_registry.py) checks that the referenced regression tests exist.
- Add or name the regression test for every fix in the same PR. Keep standing workflow rules in the workspace instructions and durable decisions in the repository.
- Read the candidate CLI output by eye before every release, including both monitor layouts. Record what was checked. [Release procedure](../../CONTRIBUTING.md#releasing)
