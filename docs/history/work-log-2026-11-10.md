## 5. Quota diet

- Measured: resumed streams are the main sink (a cx stream reused for 19 asks cost 23.6M input tokens; fresh one-shot
  votes cost about 0.1M for cx and 8k for ag; a cc implementer stream reused for 14 tasks cost 115M). Baselines per call:
  cc about 23k, cx about 17k, ag about 7.5k tokens.
- Rule now: reuse a stream within one task only; new task = new stream with a short summary; votes are one-shot
  (guide + lesson `stream-reuse-cost`, #340; workspace AGENTS.md; owner memory).
- Global instructions: `~/.gemini/GEMINI.md` held LK-only rules (3.3KB on every ag call). agy reads only the `-w`
  folder's GEMINI.md (verified with markers), so the rules moved to `D:/Engram/workspace/LK/GEMINI.md` (excluded in that
  repo's local `.git/info/exclude`) and the global file is a 208-byte pointer; verified: LK `-w` loads the rules,
  other workspaces do not. Stale codex trust entries for removed repos were dropped.
- Workspace layout: LegalWritingStrategy moved to `D:/Engram/workspace`; the local markitdown-gc clone was removed
  (worked on elsewhere); AGENTS.md routes only Engram, peerhub and VerySimpleGuide.
